# MATLAB outputs

`matlab/battery_discharge.m` writes `lipo_discharge.json` and `li-ion-18650_discharge.json` here, and
`matlab/mpu6050_lowpass.m` writes `mpu6050_lowpass.json`. The power check reads the discharge tables when they
exist (the UI then says "MATLAB discharge curve"); otherwise it uses usable capacity = 80 % of rated.
Nothing in this folder is generated by hand.
